# 🛒 Smart Store Product Detection System

This project is a **Smart Store Product Detection System** built using:
- **YOLO (Ultralytics)**
- **Streamlit**
- **OpenCV**
- A custom trained model: `best.pt`

- It supports detection from:
  
✅ Image Upload  
✅ Video Upload  
✅ Webcam (Browser webcam using `streamlit-webrtc`, works on Streamlit Cloud)
